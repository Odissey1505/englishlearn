# Lesson 02 · Three Time Worlds — фото-сцени

Поки фото немає, кожна сцена показує власну SVG-ілюстрацію (урок повністю працює без фото).
Щоб додати фото:

1. Збережи файл сюди як `<назва>.webp` (16:9, бажано 1600×900, ≤ 250 КБ).
2. У `lessons/ti-02.js` допиши назву (без `.webp`) у масив `PHOTOS` угорі файлу.

Якщо файл не завантажиться, автоматично повернеться SVG-ілюстрація.

## Персонаж (однаковий у всіх кадрах)

**Alex**, 15 років, темне волосся, темно-синє худі (navy hoodie), джинси. Реалістичний, кінематографічний стиль, без тексту на зображенні, природна анатомія рук і обличчя.
