# Lesson 02 · Three Time Worlds — фото-сцени

Усі 11 сцен і бейдж уже мають фото (листопад 2026). Якщо файл не завантажиться, урок автоматично покаже запасну SVG-ілюстрацію.

Поверх фото накладаються анімації світів (`TwPhotoFx` у `ti-worlds.jsx`): Past — спогад (проявлення з розмиття, приглушені кольори, легка імла, зерно, віньєтка); Present — «зараз» (живе світло, пульсуюча позначка); Future — ще не сталося (холодне сяйво, сканування вперед, рамка-«прогноз»); лабораторія — збій → увімкнення порталів → спокійне сяйво.

Циферблат Chrono Compass лишається SVG-елементом інтерфейсу.
Щоб додати фото:

1. Збережи файл сюди як `<назва>.webp` (16:9, бажано 1600×900, ≤ 250 КБ).
2. У `lessons/ti-02.js` допиши назву (без `.webp`) у масив `PHOTOS` угорі файлу.

Якщо файл не завантажиться, автоматично повернеться SVG-ілюстрація.

## Персонаж (однаковий у всіх кадрах)

**Alex**, 15 років, темне волосся, темно-синє худі (navy hoodie), джинси. Реалістичний, кінематографічний стиль, без тексту на зображенні, природна анатомія рук і обличчя.
